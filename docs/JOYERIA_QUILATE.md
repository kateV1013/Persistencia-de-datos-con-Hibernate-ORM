# Joyería Quilate

Joyería Quilate es un proyecto académico de gestión de inventario, ventas,
apartados y pedidos personalizados. La interfaz usa verde esmeralda, dorado
y marfil.

El catálogo, los clientes, los importes y los servicios de demostración son
ficticios. Consulta [la guía de la base de datos](../database/README.md) para
conocer los datos de ejemplo y el procedimiento de carga.
